## 当前功能

- 核心机制：混沌之力、受击轮盘、两仪、混沌孤注、开天辟地、裁决、掌控混沌。
- 改签恢复为默认开启的可切换被动；攻击触发两仪时按等级多次判定，保留较高结果。配置关闭、用户状态关闭、无本次攻击记录、资源关闭、余额不足和成功改签保持六个互斥路径。
- 改签消耗默认 1；开天辟地默认 10。两者均有独立 0–20 滑条，位于各自核心开关下方。
- 改签不会重投受击轮盘，不改变总览中的正面、负面、平息概率。
- 保留负面保护：同类强负面不重复叠加或刷新，并降低再次抽中权重。
- 额外便利与核心分区；身份、熟练项、种族能力、瓦罗眼等设置仍保留。
- 负重功能使用独立勾选镜像；移除额外设置汇总列表，保留混沌总览、剩余掌控点数、最近受击记录。

## 本轮恢复与验证

- 从删除改签提交 e116398 的父版本恢复对应规则，不整体回滚版本。
- 显式恢复被 1.0.1.91–93 删除的旧存档改签被动。
- 恢复既有攻击路径真值表与变异检查，覆盖免费消耗、余额不足以及关闭状态。
- 保留较新负重、负面保护、分区及其他回归检查。
- 静态、编译和包校验不等于游戏内验收。

## 待游戏内验证

1. 原存档是否重新获得命运改签被动，默认状态及菜单开关是否可操作。
2. 改签消耗为 0 时，有效两仪攻击能否触发且不扣混沌之力。
3. 消耗为 1 时，有效命中只结算一次；不足时是否不扣费。
4. 关闭改签后两仪是否仍正常单次结算。
5. 负重取消后上限下降，重新开启恢复，反复切换不叠加。
