# 最小起源回退说明

## 回退原因

完整 Story 实现出现默认女性半精灵和守护者异常。检查确认，起源主体字段与 `ChaosOriginsRemastered` 一致，但新的 Story 实现存在两项关键结构偏离：

1. 在 `UserAvatarCreated` 阶段立即执行全部标签、能力、配置和机制同步，而 SE 验收版等待角色创建完成后再延迟同步；
2. 混沌起源唯一 `ReallyTag` 被错误分类为 `Race` 和 `PlayerRace`，使起源身份参与角色创建的种族判定。SE 验收版使用 `Code`、`Dialog`、`DialogHidden`。
