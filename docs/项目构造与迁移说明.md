# Story 项目构造与迁移说明

## 模块身份

- 模块：`ChaosOriginsStory`
- 模块 UUID：`a5062238-0d2b-46d1-a093-cb02775b9f57`
- 起源 UUID：`b751ba19-8aeb-4da5-a515-cf853e4c459c`
- Stats 前缀：`COS_`
- SE 参考：`reference-se/` 版本 `1.0.25`

Story 版使用独立身份，可与 `ChaosOriginsRemastered` 共存。它不读取 `reference-se/` 参与打包，也不依赖 SE、MCM 或 Lua。

## 运行结构

静态起源、熟练、技能、法术、状态与动作资源位于 `story-src/Public/ChaosOriginsStory/`。原生 Story Goal `COS_ChaosOrigins.txt` 负责角色注册、身份/能力幂等授予、剧情 Flag 奖励、迷失与混沌之力数据库、受创锁、伤害轮盘和击杀计数；`COS_Config.txt` 负责按角色持久化设置、授予账本、权限校验、页面事件协议和设置手册操作。

角色手册通过 RootTemplate 打开原生 SpellContainer，并使用 Story 设置数据库与主机/控制权/战斗/忙碌锁校验，不依赖 NMCM、MCM、SE 或 Lua。暂停菜单 XAML 扩展因实机进入游戏时在客户端 `Load` 阶段崩溃，已从正式包移除。

构建先编译 Story 和两个 LSF 资源，再编译四语 LOCA。`package-files.json` 固定正式包为 20 个文件；打包后反向解包并逐文件比较 SHA-256。

## 设置默认值与撤销边界

- 八项玩法机制、七项起源身份、十五项受击负面结果默认开启；
- 二十项去重后的官方可选种族被动均有独立开关，默认关闭，并支持一键全选和取消；
- 种族被动开启前检查角色是否已拥有同 ID 被动；只有本模组新增的被动才写入授予账本，关闭时也只按账本撤销；
- 设置按混沌角色保存，手册通过 `TemplateIsInInventory` 幂等补发，重复同步不会复制。

## 伤害迁移

- 受创：每个混沌角色从本回合开始到下回合开始只处理首次有效 `AttackedBy`；11 项非负面结果固定入池，十五项负面结果仅在各自开关开启时入池，所有当前候选等概率，只有敌方造成的负面结果累积迷失。
- 回响：按汇总伤害计算 30% 追加力场伤害或 20% 治疗；无来源追加伤害不递归。
- 孤注/强袭/必杀：命中后补足倍率；三者同时存在时追加 7 倍，使总伤害为 8 倍。
- 两仪：目标存活时回补汇总伤害的一半，再结算另一半。可近似吞噬、返还、随机元素、1.5 倍与 2 倍；无法复刻 SE 的伤害前逐类型拆分、延迟、换目标和多目标分发。

## 尚需实机验收

1. 新建角色、男女守护者、自由种族/职业/体型；
2. 1–12 级升级，确认没有额外专长；
3. 受创每轮锁、迷失读档持久化和混沌之力显示；
4. 1 点伤害、致死伤害、临时生命、多段魔法飞弹和范围伤害下的两仪；
5. 孤注/强袭/必杀的单项与组合倍率；
6. 11 个剧情 Flag 的补发、阶段替换、撤销与一次性消耗；
7. SE 与 Story 同时启用时角色创建和存档隔离。
8. 设置手册的四类设置、100 项逐项操作、批量操作、读档/换图/死亡后的唯一性；
9. 战斗中手册操作只读，非主机控制角色不能修改；
10. 原生同 ID 种族被动不被关闭操作误删，模组授予项能正确撤销。

编译/静态检查、安装哈希一致与上述实机验收不得混为一谈。
