# 1.0.1.86：批量关闭与标签种族法术

## 变更

- 各组批量按钮居中，显示“全部开启 / 全部取消”。取消仅关闭已启用项，不再反选。
- 官方种族被动保留原有两按钮，删除重复的一排。
- 瓦罗之眼上方新增默认关闭的“标签种族法术与能力”。
- 按选中标签及角色等级授予22条原版固定法术记录，合并为18个独立授予来源。
- 支持吉斯洋基、卓尔及半卓尔、灰矮人、三种提夫林和森林侏儒对应固定法术。其他没有固定主动法术的标签不擅自添加技能。
- 自选戏法、龙裔血统选择不在此功能范围；已有种族被动菜单仍单独控制被动。
- 标签切换、升级、洗点完成、读档走现有同步入口。关闭只移除本 MOD 新增来源，不删除原版法术。
- 种族装备效果总开关尚未实现。

## 验证

完整 verify.ps1、原生 Story 编译、资源编译及 PAK 反向校验通过。
游戏内效果尚待测试，构建通过不等同于交互验收。

4. 关闭新开关，确认角色原来已有的同名法术仍可用。
5. 升级、洗点及存读档后再次核对，检查地狱叱喝反应资源及休息限制。
