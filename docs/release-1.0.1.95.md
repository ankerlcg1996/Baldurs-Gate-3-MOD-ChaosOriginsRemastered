# 1.0.1.95：改签观察与同步候选

## 变更

- 改签成功后，以角色头顶短文字提示实际判定次数、采用的两仪基础倍率和扣除的混沌之力。
- 对有效伤害触发链，分别说明改签关闭、被动未开启、无本次攻击记录、混沌之力关闭、余额不足或两仪关闭；均注明未扣费。
- 每个角色保留最近一条记录，打开混沌设置时重看；同一会话内按 StoryActionID 去重，交错的伤害事件不会重复提示同一行动。加载关卡时清理去重表，保留最近记录。
- 菜单设置投射到改签被动；技能栏状态事件反向同步菜单。程序发放与校准被动时使用同步保护，不把内部操作当作玩家操作。
- 保留四类生命周期校准：加载、升级、洗点、切换主控。状态一致时不重复翻转。

## 明确边界

- 提示是原生 DebugText 短文字，并同时调用原生 DebugLog；不承诺它作为一行记录出现在游戏战斗日志面板。
- 基础倍率不是最终伤害，后续两仪类型、时机和延迟结算仍照旧。
- 未命中或没有有效正数伤害时，不凭中间事件猜测原因；这类攻击不生成上述结算记录。
- 最近记录仅供回看，不重复施加效果或扣费。没有恢复已删除的额外设置汇总列表。
- 保存与重载已由用户确认正常，没有替换其持久化方案。

## 游戏内验收

静态检查和编译不能证明原生事件时序。需要测试菜单关闭后技能栏熄灭、技能栏开启后菜单勾选，以及关闭状态经过读档/洗点后不被重新开启。
检验 0、1、20 三档消耗，观察真实扣费与提示一致；多目标、多伤害类型攻击不重复提示。版本安装状态以最终交付说明为准。
