# 混沌起源核心设置落地 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已通过游戏启动门禁的原生设置菜单空壳接入纯 Story 配置后端，使混沌起源角色可以即时、持久地开关九项核心机制，并保留旧存档数据。

**Architecture:** `COS_Config.txt` 是配置写入与回显同步的唯一入口，`DB_COS_ConfigMechanic(Character, Key, Enabled)` 是唯一真实来源；XAML 只发送固定 TutorialEvent UUID，并通过九个 `IsHidden` 被动读取当前状态。现有菜单状态机不增加新状态，避免恢复曾导致新游戏崩溃的旧实现；身份能力、随机结果和设置手册在本版本通过实机门禁后分别实施。

**Tech Stack:** BG3 原生 Osiris Story、BG3 Stats、TutorialEvents LSX、Larian XAML、PowerShell 7、LSLib、StoryCompiler、仓库自带静态/IR/反向解包验证。
