# 原生设置菜单空壳 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不读取角色数据、不发送 Story 请求的前提下，为 `ChaosOriginsStory` 加入可打开和关闭的 NMCM 式原生暂停菜单空壳。

**Architecture:** 键鼠和手柄状态机只扩展 `Paused` 与 `SystemUIs`，再注册独立模态状态 `COS_CFG_MENU`。空壳页面只使用 BG3 原生样式、本地化和 `CloseWidget`，不绑定角色、被动、TutorialEvent 或配置数据库；现有 Story 与 Stats 完全不改。

**Tech Stack:** BG3 原生 XAML 状态机、LSX/LSF、PowerShell 7、LSLib Divine、现有 StoryCompiler/PAK 反向校验流程。

---
