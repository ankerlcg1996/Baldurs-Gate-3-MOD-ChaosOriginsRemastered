# 瓦罗魔法眼实施计划

用户已授权自行设计并直接执行，不再等待设计确认。

**目标：** 1.0.1.79 为混沌角色增加默认开启的瓦罗魔法眼设置；救援成功后获得原版识破隐形机制，不推进挖眼剧情。

**原生证据：** Gustav.pak 的 Act1_GOB_VoloBallad 在 MoveVoloToCamp 设置 GOB_VoloBallad_State_VoloEscaped_13ae819f-b0b7-434d-9ebb-cee412b1a407。Act1_CAMP_VoloOperation 单独设置挖眼、眼睛材质及 LeftAfterOperation，明确拒绝手术也会离营。CAMP_Volo_ErsatzEye 使用 MAG_SEE_INVISIBILITY_HIDDEN_IGNORE_RESTING，此状态继承 SEE_INVISIBILITY。

**设计：** 默认开启的偏好按混沌角色存入 DB；菜单沿用已有 TutorialEvent 和可见镜像被动。独立 COS_VOLO_EYE 状态继承原生 MAG 状态，使用独立 StackId，避免关闭时移除正常挖眼能力。授予条件为 GetFlag(救援完成,NULL,1) 且设置开启且无正常魔法眼被动。救援事件、配置打开、载入/获得控制、长休和复活刷新。关闭只移除本 MOD 状态；正常魔法眼获得时撤下副本状态。不修改任何官方旗标、人物外观、营地对象。
