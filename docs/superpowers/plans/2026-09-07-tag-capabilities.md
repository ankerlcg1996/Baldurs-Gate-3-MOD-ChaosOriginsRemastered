# 标签能力与批量选择实施计划

沿用 codex/native-core-config 工作树，逐项实施与验证，不以构建代替游戏验收。

## 1. 分组批量选择

- 核心机制9项、起源7项、身份标签31项、武器31项提供居中的全部开启/全部取消；官方种族被动20项沿用原有两个按钮。
- 修改 COS_Config.txt、两套 COS_ConfigMenu.xaml、TutorialEvents.lsx、四语言本地化。
- 复用现有切换/授予逻辑；原生标签保护和旧档来源不明保护不变。
- 先运行 `pwsh -NoProfile -File story-src/verify-bulk-menu.ps1` 验证缺失入口失败，再实施并运行完整 verify.ps1。

## 2. 标签种族固定能力

- 提取原生 Progressions 固定授予，排除 SelectSpells、SelectSkills 和血统选择。
- 保留原生等级、施法属性及 UntilRest 等参数，使用独立来源承载撤回。
- 默认关闭；入口在瓦罗魔法眼上方；改标签、升级、洗点、读档同步。
- 验证等级门槛和关闭后原生/职业同名能力保留。

## 3. 种族装备资格

- 审计本体及补丁的精确装备条件，不替换整个种族。
- 默认关闭仍保留真实种族资格，开启增加选中身份资格。
- 验证吉斯洋基专用武器及其他已枚举装备；未知模组装备不承诺兼容。

## 4. 发布

- 保持可翻译标题与 Name.Str 比较键分离。
- 全部完成后再构建下一正式版，核对包、安装和远端提交。
- 阶段源码可备份，但不得将未完成阶段宣称为完整需求。
