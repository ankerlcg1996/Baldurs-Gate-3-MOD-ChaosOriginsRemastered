# 掌控混沌运行时成长 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以纯原生 Story 为混沌起源实现1–12级掌控点、同屏双路线选择、免费洗点重选、300格受击轮盘与12个自动解锁正面结果，并分两次构建完成实机验收。

**Architecture:** 删除已经实机证明无效的 Origin Progression/PassiveList 注入，改由独立 `COS_ChaosMastery` Story Goal 按角色等级幂等发放隐藏资源载体；一个链接容器技能承载“调律”和“厄兆纠偏”两个子技能，子技能消耗1点资源并增加对应永久状态层数。受击轮盘先在300格中判定正面、负面或平息，再进入独立权重池；命运改签重复完整判定并按结果评级保留最优结果。

**Tech Stack:** BG3 Stats `.txt`、ActionResourceDefinitions `.lsx`、Osiris Story、StoryCompiler、LSLib、PowerShell 静态校验与四语本地化。
