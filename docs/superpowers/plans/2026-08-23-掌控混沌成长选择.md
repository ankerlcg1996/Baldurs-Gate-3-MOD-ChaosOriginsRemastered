# “掌控混沌”成长选择实现计划

> 执行本计划时按任务顺序推进。一级原生选择是强制实机门槛；门槛未通过前不得扩展到2–12级，也不得改用 Script Extender、临时技能或对话框伪装升级选择。

## 目标

为混沌起源增加1–12级每级一次的原生三选一成长，按已批准公式重构受击轮盘，并让玩家在升级界面和角色被动列表中按 T 查看正面、负面、平息以及所选新增BUFF的完整说明。

## 架构

- 复用官方起源成长的原生结构：`ProgressionDescriptions` 使用 `Origin_ChaosStoryMinimal`，其 `ProgressionTableId` 指向本MOD独立成长表。
- `Progressions.lsx` 在1–12级分别调用一个 `SelectPassives(列表UUID,1,ChaosMasteryLevelN)`。
- `PassiveLists.lsx` 每级只包含该级的调律、厄兆纠偏和新增BUFF三个被动。
- 不向 `Origins.lsx` 增加 `ProgressionTableUUID`。当前起源 `Name="ChaosStoryMinimal"` 保持不变；该风险字段继续由校验器禁止。
- 36个选择被动只负责保存玩家选择并提供可见说明。Story在每次受击判定前从 `HasPassive` 重建 `A / B / C`，不保存第二份可能失步的成长状态。
- 受击轮盘先判定正面或负面候选，再对负面候选判定平息，最后从对应权重池抽取具体结果。
- 命运改签重复完整的“类别+平息+池内结果”判定并保留命运评级最高的完整结果。
- 所有新数据均为原生 Stats、LSX、本地化和 Osiris Story；不增加 SE、MCM 或 NMCM 依赖。

## 已核对的官方数据模式

- 官方 `SelectPassives` 结构为 `SelectPassives(PassiveListUUID,选择数,SelectorId)`。
- 被动候选来自 `Public/<Module>/Lists/PassiveLists.lsx` 的 `PassiveList` 节点。
- 官方起源成长使用隐藏的 `ProgressionDescription`，`Type="Origin_<起源名>"`，并由同名 `Progression.Name` 和同一个 `TableUUID` 提供等级节点。
- 当前安装游戏的官方起源表采用上述结构；计划不依赖网页或未验证的第三方模板。

## 标识约定

- 调律被动：`COS_ChaosMastery_Tune_L01` 至 `COS_ChaosMastery_Tune_L12`。
- 厄兆纠偏：`COS_ChaosMastery_Correct_L01` 至 `COS_ChaosMastery_Correct_L12`。
- 新BUFF选择：`COS_ChaosMastery_Buff_L01` 至 `COS_ChaosMastery_Buff_L12`。
- 类别详情：`COS_CHAOS_MASTERY_POSITIVE_INFO`、`COS_CHAOS_MASTERY_NEGATIVE_INFO`、`COS_CHAOS_MASTERY_CALM_INFO`。
- 新BUFF结果状态：`COS_CHAOS_MASTERY_RESULT_L01` 至 `COS_CHAOS_MASTERY_RESULT_L12`。
- 每个 LSX 节点使用一次性生成并写入源文件的固定 UUID。校验器拒绝空值和重复值；运行时不生成 UUID。
