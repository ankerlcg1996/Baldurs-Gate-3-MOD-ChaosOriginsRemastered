# 五级法术与无限山莓 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让混沌起源在角色总等级 5 获得三项指定技能，并让所有原版山莓无限使用、保留治疗表现但实际治疗为 0。

**Architecture:** 五级技能使用 MOD 专用 SpellData 副本，并接入现有 `DB_COS_CoreSpell` 等级同步。山莓通过同 MapKey 的完整 RootTemplate 覆盖修改 `OnUsePeaceActions`，再套用一个继承官方 `FOOD`、不含治疗 Functor 的状态。两项功能分别完成测试和提交，最后统一构建、安装和推送。

**Tech Stack:** BG3 Stats、Osiris Story、LSX/LSF、PowerShell 7、LSLib Divine、现有 `verify.ps1`/`build.ps1`。
