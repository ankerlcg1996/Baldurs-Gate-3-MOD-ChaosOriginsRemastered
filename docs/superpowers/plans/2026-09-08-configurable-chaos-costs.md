# 独立混沌之力消耗设置

目标：两个独立 0–20 整数控件，命运改签默认 1、开天辟地默认 10；0 免费，其他施放条件不变。沿用已有原生菜单加减滑条与手柄左右调节，不引入 SE。

- [x] 新增 verify-power-costs.ps1，验证缺少动态消耗时失败。
- [x] COS_Config.txt 增加每角色 DB_COS_ConfigCost(Character,Key,Value)，运行时播种新键/事件以支持旧存档；只补缺失设置。
- [x] 使用两个隐藏 ActionResource 作为菜单回显，不作为权威账本。更新时从对应角色 DB 重建。
- [x] 改签的余额不足分支由余额等于 0 改为余额小于当前消耗；成功分支使用余额大于等于当前消耗并准确扣费。保持每个攻击动作最多一次。
- [x] 开天辟地准备状态与实际扣除同时使用其独立消耗。设置更改后刷新准备状态。
- [x] 键鼠/手柄菜单各新增两行加减滑条和恢复默认按钮，固定 TutorialEvent；非战斗、受控混沌角色才能修改。
- [x] 四语言说明不再断言固定消耗，新增菜单说明标明 0 免费。
- [x] 全量验证/Story 编译/打包递增版本，导出桌面 MOD 目录、GitHub 备份；实机显示与读档仍待验收。

边界测试：两种设置互不覆盖；0/1/10/20；低于、等于、高于成本；未命中不扣改签；核心机制关闭仍不触发；打开菜单不覆盖旧值；调整不增减现有混沌之力；旧存档能得到新控件。
