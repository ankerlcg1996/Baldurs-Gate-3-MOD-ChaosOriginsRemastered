# 混沌起源：仅保留种族身份设计

## 目标

降低混沌角色强度。保留全部官方可选种族与亚种的身份标签，但不再由本 MOD 额外授予任何种族被动或种族法术。

## 行为边界

- 保留玩家角色创建时所选原生种族及其原版正常能力。
- 保留本 MOD 追加的全部种族与亚种身份标签，继续参与对话和剧情判定。
- 停止授予额外 20 项官方种族被动。
- 停止授予通过隐藏被动解锁的 29 个额外种族法术。
- 不改变七项起源身份、初始七法术、技能精通或混沌机制。

## 旧存档处理

角色同步时，根据 `RaceGranted.Passives` 账本精确移除旧版本由本 MOD 授予的种族被动与种族法术解锁被动。原生种族能力不在该账本内，因此不得删除。

种族身份标签继续由 `RaceGranted.Tags` 维护，不需要修改存档结构或重置角色状态。

## 验证

- 新角色只获得额外种族身份标签，不获得额外种族能力或法术。
- v1.0.20 旧存档载入后，旧版额外种族能力被移除。
- 玩家所选原生种族的正常能力仍然存在。
- 全部种族身份标签数量与顺序保持不变。
- 构建、反向解包、安装哈希和 Git 提交继续通过现有流程验证。
