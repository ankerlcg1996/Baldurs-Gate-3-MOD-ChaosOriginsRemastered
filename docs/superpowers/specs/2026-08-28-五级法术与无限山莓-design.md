# 五级法术与无限山莓设计

## 目标

为纯 Story 版 `ChaosOriginsStory` 增加两组能力：混沌起源在角色总等级达到 5 级时获得三项固定技能；原版山莓对所有角色变为无限使用的零治疗道具。

本功能不依赖 Script Extender、MCM、NMCM 或外部前置。MOD 通过同名资源覆盖改变运行时数据，不修改游戏安装目录中的官方 PAK。

## 五级技能

### 授予范围

只有带有 `COS_ChaosOriginMarker` 的角色获得技能。系统读取角色总等级，不读取单一职业等级。

角色达到 5 级后获得：

| 技能 | 行动消耗 | 资源消耗 | 冷却与专注 |
| --- | --- | --- | --- |
| 龙族元素武器 | 无 | 无 | 无冷却；不专注 |
| 加速术 | 1 动作 | 无法术位 | 保留原版专注 |
| 敲击术 | 无 | 无 | 无冷却；不专注 |

龙族元素武器保留酸、寒冷、火焰、闪电和雷鸣五个子技能，并沿用龙息长柄刀的原版数值、目标规则、状态和表现。

### 法术数据

不直接授予以下官方法术：

- `Target_MAG_ElementalWeapon` 带有 `OncePerRestPerItem` 和 `ActionPoint:1`；
- `Target_Haste` 带有三级法术位消耗；
- `Target_Knock` 带有二级法术位和动作消耗。

MOD 建立独立法术副本：

- 龙族元素武器容器及五个子技能继承 `Target_MAG_ElementalWeapon` 系列，绑定新的专用容器，并清空 `Cooldown` 和 `UseCosts`；
- 加速术继承 `Target_Haste`，将 `UseCosts` 固定为 `ActionPoint:1`，保留 `IsConcentration`；
- 敲击术继承 `Target_Knock`，清空 `UseCosts` 和 `Cooldown`。

独立 Stat ID 防止修改官方职业法术、卷轴和装备技能。

### 等级同步

三个技能进入现有 `DB_COS_CoreSpell(RequiredLevel, Spell)` 同步表，要求等级为 5。现有同步入口覆盖：

- 地图开始；
- 玩家取得角色控制权；
- 角色升级；
- 洗点完成。

同步过程保持幂等。5 级以上旧存档首次载入或重新取得控制权时补发缺失技能。

系统补充反向同步：混沌起源低于 5 级时移除这三个 MOD 专用技能。角色重新达到 5 级时再次获得。反向同步只处理本功能的独立 Stat ID，不删除其他来源授予的官方法术。

## 无限山莓

### 修改对象

修改原版山莓：

- Object Stat：`CONS_Berry`；
- RootTemplate：`b0943b65-5766-414a-903d-28de8790370a`；
- 模板名称：`GEN_CONS_Berry`。

该修改对玩家、同伴和其他可控制角色生效，不检查混沌起源身份。

### 使用行为

MOD 复制完整的官方山莓模板节点，以相同 `MapKey` 覆盖原节点，并且只修改 `OnUsePeaceActions`：

- 保留原版使用动作和状态应用流程；
- 将 `Consume` 从 `True` 改为 `False`；
- 将原版 `FOOD_FRUIT_GOODBERRY` 替换为 MOD 专用零治疗状态；
- 不改变山莓名称、图标、模型、重量、价值、采集来源或物品 Stat。

零治疗状态直接继承官方 `FOOD`，沿用其 `ApplyEffect`，但不声明 `OnApplyFunctors`。因此使用山莓时保留治疗表现，却不会执行 `RegainHitPoints`，生命值变化恒为 0。

系统不采用“消耗后返还”或复制物品方案。物品数量从使用前到使用后保持不变。

### 作用边界

该覆盖改变世界中所有同一 RootTemplate 的原版山莓，包括已有存档库存、后续采集和商人物品。它不改变神莓术生成的 `CONS_FOOD_Fruit_Goodberry`，也不改变其他食物。

## 验证

### 自动验证

验证脚本必须证明：

- 三个专用根技能以等级 5 注册；
- 龙族元素武器包含五个专用子技能；
- 龙族元素武器和敲击术没有行动、法术位或冷却；
- 加速术只消耗 1 动作，并保留专注；
- 等级同步包含补发和低等级移除；
- 山莓覆盖使用官方 MapKey，且 `Consume=False`；
- 山莓使用的专用状态没有 `RegainHitPoints`；
- 神莓术物品和其他食物未被覆盖；
- 文件清单、Story 编译、资源编译、PAK 反向解包和逐文件 SHA-256 比对全部通过。

### 游戏内验收

自动验证不能代替以下游戏内测试：

1. 4 级混沌起源没有三项技能。
2. 升到 5 级后立即获得三项技能。
3. 5 级以上旧存档载入后自动补发。
4. 洗点到 4 级后移除，重新达到 5 级后恢复。
5. 龙族元素武器可连续释放五种元素选择，且不消耗动作或资源。
6. 加速术消耗 1 动作、不消耗法术位，并正常要求和打断专注。
7. 敲击术不消耗动作或资源，可连续打开有效目标。
8. 任意角色使用山莓后，物品数量不变，治疗表现正常，生命值不变。
9. 神莓术生成的浆果仍按官方规则消耗并治疗。

## 发布

成功验证后，将四段式版本号的最后一段加一，构建并安装新 PAK。源码和发布元数据推送到当前 GitHub 分支及主分支；PAK 按仓库现有规则保留为本地忽略的构建产物。构建、安装、哈希和推送结果分别报告；游戏内行为在用户完成验收前保持“待验收”。
