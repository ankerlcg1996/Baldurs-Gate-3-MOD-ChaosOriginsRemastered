# 生活熟练项与种族被动设置设计

## 目标

在 `ChaosOriginsStory` 的现有原生设置页中加入两类纯 Story 设置，不引入 Script Extender、MCM 或 NMCM 运行依赖：

1. “生活熟练项加值”默认开启并为 `+5`，可在 `0` 至 `20` 间逐点调整。
2. 官方可选种族的原生被动可逐项开启，默认全部关闭；同名被动只显示一次，并提供一键全选和一键取消。

这些设置只作用于当前受控、具有 `COS_ChaosOriginMarker` 的混沌起源角色，并随存档保存。

## 数值控件

采用 `前置-NMCM-原生菜单显示.pak` 已验证的纯 Story 数值通道：

- 设置页显示一条进度条、当前整数值、减号按钮和加号按钮。
- 键鼠点击减号/加号；手柄使用左右方向。
- 范围固定为 `0..20`，步长固定为 `1`，默认值为 `5`。
- 数值 `0` 表示关闭生活熟练项加值。
- 控件不是可拖拽滑块。原生 `TutorialEvent` 只能发送预先注册的固定事件，不能携带任意拖拽数值；进度条只负责显示，左右事件负责修改。
- 每次修改立即写入该角色的 Story 数据并刷新显示，不需要另点“应用”。

使用一个隐藏、永不自动恢复的 Action Resource 作为 UI 数值镜像。打开设置页时，把当前受控混沌角色的存档值同步到该资源；资源不作为玩法消耗。

## 生活熟练项加值

- 数据语义是“所有技能检定固定加值”，覆盖威吓、求生、洞察等全部技能检定。
- 使用 `RollBonus(SkillCheck,N)`，不授予技能熟练或专精，也不改变角色等级对应的熟练加值。
- 建立 `0..20` 的唯一映射；数值大于零时，角色只持有一个对应的隐藏加值被动，修改时先移除旧值再添加新值，禁止叠加。
- 旧的固定 `COS_BaseProficiencies` 中移除 `RollBonus(SkillCheck,5)`，避免默认加值和可调加值重复结算；装备、护甲、乐器等原有熟练保持不变。
- 设置页和常驻说明状态显示当前值。角色面板是否把通用 `SkillCheck` 加值预先计入每一项静态数字由本体 UI 决定；实际技能检定结算必须包含该值。

## 原生被动归属保护

混沌起源角色仍然可以选择任意正常种族，因此关闭设置时不能误删角色本来就拥有的被动。

- 开启某项时，先检查角色是否已经拥有该被动。
- 若原本没有，模组添加被动，并在 `DB_COS_RacialPassiveGranted` 中记录由模组授予。
- 若原本已有，只保存开关为开启，不把它记为模组授予。
- 关闭某项时，只在存在“模组授予”记录时移除该被动；没有记录则保留原生来源。
- 载入存档、获得角色控制、升级和洗点完成后均执行对账：补齐已开启但缺失的模组被动，移除已关闭且确由模组授予的被动。
- 不猜测未知来源，也不因设置关闭而删除无法证明由本模组添加的被动。

“全选”与“全取消”必须逐项调用同一套归属保护过程，不能直接批量增删被动。

## 设置页布局

把当前固定缩放的九行页面改成可滚动页面，并分为三个连续区块：

1. 核心机制：保留现有九个开关和恢复默认。
2. 生活熟练项：显示 `0..20` 数值步进控件及简短说明。
3. 种族被动：先显示“全选/全取消”，再显示 20 个独立开关。

键鼠和手柄页面保持同样的功能和顺序。每个被动显示本地化名称与一句效果说明；开关状态继续通过角色被动镜像显示，而不是依赖 XAML 自己持久化。

## 存档与默认值

- 新角色首次初始化：生活熟练项为 `5`，20 个种族被动均为关闭。
- 旧存档：只补不存在的新设置键，不覆盖现有核心机制设置。
- 设置值保存在 Story 数据库中，随游戏存档保存。
- “恢复默认”分别明确作用范围：核心机制恢复现有默认；生活熟练项恢复 `5`；种族被动全部恢复关闭。不得用一个模糊按钮静默改动全部分区。

## 验证边界

自动验证必须覆盖：

- 数值事件只有增、减两个固定 UUID，且 Story 对结果执行 `0..20` 夹取。
- 默认值为 `5`，所有数值被动唯一且不叠加。
- 固定 `COS_BaseProficiencies` 不再含技能检定加值。
- 20 个种族被动去重、默认关闭、每项事件唯一。
- 全选/全取消复用逐项归属保护逻辑。
- 关闭开关不会删除无“模组授予”记录的原生被动。
- XAML、控制器 XAML、TutorialEvents、ActionResource、Story Goal、本地化和打包清单相互一致。
- Story 编译、反向解包、逐文件哈希和唯一安装检查通过。

自动验证只能证明源文件、Story 编译、打包内容和安装一致性。以下仍需实机验收：新角色默认 `+5`、旧存档迁移、0/20 边界、威吓/求生/洞察实际掷骰、原生同种族被动关闭保护、全选/全取消、键鼠/手柄滚动与即时保存。
