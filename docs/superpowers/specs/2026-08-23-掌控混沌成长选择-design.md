# “掌控混沌”成长选择设计

## 1. 目标

“掌控混沌”让混沌角色在1–12级每级选择一次成长。玩家可以把负面结果改为正面结果、抵消部分负面结果，或把新的正面状态加入受击轮盘。该系统保留随机主题，同时让玩家逐步控制风险和收益。

## 2. 范围

- 使用 BG3 原生升级界面的静态 `SelectPassives` 选择。
- 1级创建混沌角色时必须完成第一次选择。
- 2–12级每次升级再选择一项，总共12项。
- 每级固定显示3项：调律、厄兆纠偏、该等级的新正面BUFF。
- 玩家可以混合三个方向，不需要前置。
- 洗点后按当前等级重新选择。
- 13级以上不再增加选择，也不再自动改变受击轮盘的正负概率。

## 3. 不在范围内

- 不使用 Script Extender、MCM 或 NMCM。
- 不在升级时运行时随机生成3个选项。
- 不保留先前讨论的复杂分支，包括多种两仪升档、多层权重修正和独立稀有千分池。
- “掌控混沌”不修改已有两仪、命运改签、混沌之力和开天辟地的现行规则。

## 4. 基础概率

当前1级受击轮盘有41个正面权重和35个负面权重：

- 正面：`41 / 76 = 53.95%`，显示为54%。
- 负面：`35 / 76 = 46.05%`，显示为46%。

新系统以54% / 46%作为固定基础值。它取消旧的5级、9级与13–30级自动提高正面概率的规则；成长只来自玩家的选择。

## 5. 选择效果与概率公式

设角色已选：

- `A` 次调律。
- `B` 次厄兆纠偏。
- `C` 次新正面BUFF。

且 `A + B + C = 已完成的选择数`。

三种选择使用固定数值：

| 选择 | 正面 | 负面结果 | 平息 | 池内变化 |
|---|---:|---:|---:|---|
| 调律 | +1% | -1% | 0 | 无 |
| 厄兆纠偏 | 0 | -2% | +2% | 无 |
| 新正面BUFF | 0 | -1% | +1% | 对应BUFF以1权重加入正面池 |

最终概率为：

- 正面：`54 + A`。
- 平息：`2B + C`。
- 负面：`46 - A - 2B - C`。

三者之和始终为100%。1–12级的所有合法组合都保证负面概率不低于22%。

### 12级典型结果

| 选择方式 | 正面 | 负面 | 平息 |
|---|---:|---:|---:|
| 12次调律 | 66% | 34% | 0% |
| 12次厄兆纠偏 | 54% | 22% | 24% |
| 12次新正面BUFF | 54% | 34% | 12% |
| 三种各4次 | 58% | 30% | 12% |

`58% / 30% / 12%`是12级均衡成长的参考值，不是强制值。

### 路线价值预算

三条路线不能只比较正面和负面的表面百分比，还要计入新增BUFF本身高于普通正面结果的强度。设计阶段采用以下统一效用标尺：

- 普通正面结果记为 `+1`。
- 负面结果记为 `-1`。
- 平息记为 `0`。
- 12个新增BUFF的整体平均强度目标约为普通正面结果的 `2倍`；这是平衡标尺，不是游戏内显示或结算数值。

按该标尺计算12级路线：

- 12次调律：`66 - 34 = +32`。
- 12次厄兆纠偏：`54 - 22 = +32`。
- 12次新正面BUFF：正面池总权重为53，其中12个新增BUFF在全部事件中约占 `54% * 12 / 53 = 12.23%`，总效用约为 `+32.23`。
- 三种各4次：正面池总权重为45，其中4个新增BUFF在全部事件中约占 `58% * 4 / 45 = 5.16%`，总效用约为 `+33.16`。

因此，新增BUFF路线获得的是更稀有但更强的正面结果，而不是额外堆高正面类别概率。混合路线的参考效用略高，但与纯路线的差值保持在约2点以内。

## 6. 受击轮盘结算

每次有效受击轮盘按以下顺序结算：

1. 计算正面概率 `54 + A`。
2. 生成1–100的随机数。随机数落入正面区间时，进入正面池。
3. 其余结果成为负面候选。
4. 对负面候选执行平息判定。平息在全部事件中的绝对概率为 `2B + C`；其在负面候选中的条件概率为 `(2B + C) / (46 - A)`。
5. 平息成功时，取消负面状态，显示“混沌平息”日志，并结束轮盘。
6. 平息失败时，进入负面池。
7. 对应状态池按内部权重抽取一个结果。

平息只拦截负面候选，不占用正面概率。例如只选择1次厄兆纠偏时，46%事件先成为负面候选；其中约 `2 / 46 = 4.35%` 被平息取消。最终结果是54%正面、44%负面和2%平息。

## 7. 池内抽取

### 正面池

保留现有正面结果的内部权重。玩家每选择1个新正面BUFF，对应结果以1权重加入正面池。

新增BUFF不会提高正面类别概率。它在负面候选中增加1%平息，并把一个高于普通正面结果强度的新结果以1权重加入正面池。

若角色只选择1级“浮光护体”：

- 正面概率为54%，负面概率为45%，平息概率为1%。
- 正面池总权重从41变为42。
- 浮光护体在正面池内的概率为 `1 / 42 = 2.38%`。
- 浮光护体在全部受击轮盘中的实际概率约为 `54% * 1 / 42 = 1.29%`。

### 负面池

保留现有负面结果和强度权重。轻度惩罚保持较高权重，严重惩罚保持较低权重。新系统只改变进入负面池的概率，不重新放大池内惩罚。

## 9. 新正面BUFF的命运评级

命运改签重复“类别判定+池内判定”，然后保留评级最高的完整结果。类别优先级为：

1. 正面。
2. 平息。
3. 负面。

新增BUFF使用递增评级，确保高级结果优先于低级结果：

| 等级 | BUFF | 命运评级 |
|---:|---|---:|
| 1 | 浮光护体 | 17 |
| 2 | 元素薄膜 | 18 |
| 3 | 清醒回响 | 19 |
| 4 | 镜面闪烁 | 20 |
| 5 | 流光甲壳 | 21 |
| 6 | 无定护幕 | 22 |
| 7 | 反相治愈 | 23 |
| 8 | 行动裂隙 | 24 |
| 9 | 命运护盾 | 25 |
| 10 | 逆时借贷 | 26 |
| 11 | 因果拒斥 | 27 |
| 12 | 万象归一 | 28 |

混沌平息评级为15，严格位于现有负面结果最高评级12与现有正面结果最低评级16之间。现有正负结果继续使用现行评级；实现时每个新结果只能有一个评级映射。不同结果允许使用相同评级数值。

## 10. 界面与说明

- 每个选项显示精确的+1%、-1%、-2%和平息值。
- 新正面BUFF的说明同时显示“负面概率-1%，平息概率+1%，并以1权重加入正面池”。
- “混沌平息”显示独立的状态名称和战斗日志，不显示一个持续性图标。
- 所有返还伤害的效果都在受击后结算。它们无法挽救已经致死的攻击，选项说明必须明示该限制。
- 同一等级的三个被动互斥；选定后，升级界面不保留未选项。

## 11. 数据与结算边界

实现需要以下独立数据：

- 12个升级选择组，每组3个被动。
- 12个调律被动、12个厄兆纠偏被动和12个新BUFF被动。
- 12个新的正面轮盘结果。
- 1个混沌平息日志结果。
- 每个新BUFF的状态、本地化和命运评级。
- 当前角色的 `A / B / C` 计数，该计数从已选被动重建，不另外保存一份可能失步的数据。

系统必须以已选被动为唯一事实来源。读档、洗点、加入队伍和获得控制时，Story都重建计数与可用池。

## 12. 错误处理

- 选择数与角色等级不一致时，校验和构建必须报错；不自动补选。
- 等级选择组缺少被动、UUID重复、本地化缺失，或同一结果存在多个命运评级映射时，构建失败。
- 正面、负面和平息的计算结果之和不是100%时，校验失败；实现公式必须为 `54 + A`、`46 - A - 2B - C`、`2B + C`。
- 系统不使用默认被动、自动选择或无提示降级来隐藏错误。

## 13. 验收

### 静态校验

- 存在12个等级选择组，每组恰好3个唯一选项。
- 存在36个成长被动，每个等级的三个选项互斥。
- 12个新BUFF各有1个正面池权重和恰好1个命运评级映射。
- 穷举1–12级的所有 `A / B / C` 组合，验证三类概率之和始终为100%，且没有负数。
- 穷举12级全调律、全纠偏、全新BUFF和三种各4次的参考值。
- 按“普通正面+1、负面-1、平息0、新增BUFF平均+2”的设计标尺，验证四条12级参考路线的总效用差值不超过2点。
- 原生 Story 编译零错误，PAK反向校验通过。

### 实机验收

- 创建1级混沌角色时，升级界面强制显示3个选项，选择1个后可以正常进入游戏。
- 2–12级每级只显示对应的3个选项，并且只允许选择1个。
- 洗点后可以重新选择，旧被动与旧池条目全部移除。
- 调律、厄兆纠偏和新BUFF选择准确改变战斗日志中的正面、负面与平息结果。
- 平息只取消负面候选，不吞掉正面结果。
- 命运改签重复完整判定，正确按评级保留最优结果。
- 四种12级参考路线的长时间实测分布在允许的随机误差内接近规范概率。
- 反相治愈和因果拒斥不会复活被本次攻击击杀的角色。

## 14. 实现前验证点

BG3原生升级界面的静态被动选择可以表达每级3选1。实现计划必须先用最小1级选择切片验证两项风险：

1. 该选择只绑定混沌起源，不影响其他起源、种族或职业。
2. 1级创建选择不会再现过去“进行抉择”无法完成创建的问题。

该切片通过后才能扩展至2–12级。失败时应报告原生 Progression 边界，不改用 Script Extender 或升级后临时技能伪装成原版升级选择。
