# 1.0.1.80 魔法眼永久解锁和统一开关

用户明确要求直接实施，不再等待方案确认。本版替代 1.0.1.79 的原生魔法眼不受开关影响规则。

## 规则

- 默认开启只代表偏好。第一次解锁同时要求地精营地救援完成和 Volo AtCamp 旗标。
- 解锁写入永久 DB_COS_VoloEyeUnlocked(1)，不会在关闭或瓦罗离营后清除。是否做手术、拒绝手术不影响已经获得的资格。
- 对旧档，救援完成且原版 LeftAfterOperation 标记成立，是已经到过营地并进行/拒绝手术的历史证据，也允许解锁；不把单纯开关或单纯持有眼睛当作救援证据。
- 开启时根据有无原生魔法眼恢复相应识破效果；关闭时移除 MOD 效果，并用独立状态对魔法眼专用识破状态提供 StatusImmunity，防止原生被动自动补回。
- 关闭不移除手术载体 CAMP_VOLO_ERSATZEYE，不改变外观或任务旗标。只停用对应识破效果；普通识破隐形法术不在本开关范围内。
- 双旗标任意先后触发都重新检查；读档/主控切换/设置页、长休、复活继续同步。
