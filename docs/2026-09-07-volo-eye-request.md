# 待设计：瓦罗魔法眼开关

最初随 1.0.1.78 记录；用户随后授权自行设计并实施，已加入 1.0.1.79，详见 2026-09-07-volo-eye-1.0.1.79.md。游戏内验收待用户进行。

## 用户目标

- 完成地精营地拯救瓦罗后，无需选择挖眼治疗，自动获得魔法眼球的识破隐形能力。
- 提供开启、关闭该能力的选项。
- 不通过触发挖眼剧情发放能力，以避免该剧情导致瓦罗离营。

## 建议方案，待确认

沿用原生 Story 和当前混沌设置菜单。读取官方救出瓦罗的任务条件，独立授予原版魔法眼识破隐形效果；不写入挖眼完成标记，不触发瓦罗离营，不改变眼睛外观。开关只控制本 MOD 授予的能力，不移除玩家通过正常挖眼取得的能力。

替代方案是使用自定义同类识破隐形状态，但可能与原版效果产生差异；不建议伪造完成挖眼任务，因为它可能同时推进离营逻辑。

## 待核实与验收边界

- 核实官方救出瓦罗的精确任务标记、原版能力标识、授予对象（主控混沌角色或其他范围）。
- 核实已完成救援的旧存档补发方式，以及读档、长休后的状态同步。
- 开启时采用原版识破隐形效果及其正常判定，不擅自增强为必定识破。
- 不承诺瓦罗永久留营：其他章节和剧情引起的离营不属于本功能。
- 需要游戏内验证救援发放、开关、正常挖眼兼容、瓦罗后续剧情。

下一步先确认简短设计，再实施；不混入当前备份版本。
