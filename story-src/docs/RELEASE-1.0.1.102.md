# ChaosOriginsStory 1.0.1.102

## 结果

`1.0.1.102` 是配置菜单性能与布局修复候选。它恢复全部旧版细分设置，保留七个分类总开关和四套预设，并移除主页面的大型运行诊断框。

游戏内验收状态：`GAMEPLAY=UNTESTED`。

## 主要修改

- 将七个分类的细分控件从 `StatusEffects` 动态模板移回静态页面树。
- 将页面的角色状态列表绑定从 27 处降到 4 处。
- 保留旧版完整命名控件集合、74 个授权细分选项、批量按钮、滑条和四语内容。
- 将分类总开关嵌入原生金色装饰标题，移除单独的宽分类行、实际状态列和暂停遮罩。
- 保留预设选择、预览、应用和取消。
- 生活熟练项单步与重置不再刷新全部分类实际状态和运行诊断。
- Story 运行诊断状态和数据仍保留，但不在主配置页持续渲染。
